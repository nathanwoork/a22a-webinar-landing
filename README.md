# A22A webinar landing page (prototype)

Example landing page for the A22A free webinar funnel, in the A22A brand.

- `index.html` is a single self-contained file (fonts, logos and styles are embedded).
- Served with GitHub Pages from the `main` branch root.

Figures and copy in square brackets are placeholders. The sign-up form is a demo: it saves nothing. The calendar connection test only works when the page is opened inside claude.ai.
